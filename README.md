# Avery AI (Fabric 1.20.1)

ИИ-игрок Эвери. Появляется рядом с тобой при входе в мир, отзывается на «Эвери» / «Avery»,
отвечает в чате через нейросеть (по твоему API-ключу), ходит, добывает, крафтит, дерётся,
принимает вещи и ложится спать, когда спишь ты.

## Как собрать .jar (без ПК)
1. Создай репозиторий на GitHub и загрузи туда всё содержимое этой папки.
2. Вкладка **Actions** → **build** → **Run workflow**.
3. Через 2–3 минуты внизу страницы запуска, в **Artifacts**, скачай `avery-ai` (внутри `avery-ai-0.1.0.jar`).

(На ПК: `gradle build`, jar лежит в `build/libs/`.)

## Что положить в папку mods (Zalith, Fabric 1.20.1)
- Fabric API
- Mod Menu и Cloth Config (для кнопки настроек)
- Simple Voice Chat (для голоса; он нужен и тебе, и на сервере/в мире)
- avery-ai-0.1.0.jar (НЕ `-sources.jar`)

## Ключ API
- **Главное меню → Моды → Avery AI → кнопка настроек → «🔑 Ключ API»** (там же URL, модель, ник, имена, болтовня)
- Запасной вариант, в игре: `/avery key <твой ключ>` (нужен режим читов или оператор)
- Или файл `config/avery.json`, поле `apiKey`
- По умолчанию Groq: https://console.groq.com/keys. Модель, адрес и ник меняются там же (`/avery model`, `/avery url`).

## Характер и самостоятельность
Настройки → вкладка **Характер**: самостоятельность, как часто принимает решения, непредсказуемость (0–100), маты, шутки, привычки, болтовня.
- Сам выбирает занятия: добыча, крафт, исследование местности, сундуки, дом (set_home / home), сон.
- Привычки по времени суток: утро (сундуки), день (дела), вечер (домой и разложить вещи), ночь (у кровати, поболтать).
- Помнит заметки и обещания, настроение, отношение к игроку (от -100 до 100) и дом. Всё в `config/avery-memory.json`.
- Замечает открытые алмазы, изумруды, древние обломки, спавнеры, колокол и жителей рядом и реагирует.
- Каждое «решение» это 1 запрос к нейросети. Чем чаще, тем быстрее кончатся лимиты бесплатного ключа (по умолчанию раз в 60 секунд).

## Голос
- **Слух:** говоришь в войс-чат рядом с Эвери (до 24 блоков), фраза уходит на распознавание (по умолчанию Groq Whisper, тот же ключ) и обрабатывается как сообщение в чате. Обращайся по имени. Распознанный текст появится у тебя в чате с 🎤.
- **Озвучка:** Настройки → вкладка «Голос» → включи «Озвучка ответов», впиши ключ, URL, модель и голос. Сервис должен быть совместимым с OpenAI `/audio/speech` и отдавать **WAV**. По умолчанию стоит OpenAI (`tts-1`, `alloy`), он платный. Другой сервис подставь сам.
- Выключено = Эвери отвечает только в чат.

## Команды
`/avery spawn`, `/avery despawn`, `/avery key`, `/avery model`, `/avery url`, `/avery status`

Проверка тела Эвери без нейросети: `/avery act mine oak_log 3`, `/avery act place cobblestone 3`, `/avery act break`, `/avery act equip iron_chestplate`, `/avery act craft crafting_table`, `/avery act follow`, `/avery act stop`.

## Как общаться
Пиши в чат «Эвери, иди за мной», «Avery, добудь 10 дубовых брёвен», «Эвери, скрафти верстак».
После ответа он ещё 60 секунд слушает тебя и без обращения по имени.
ПКМ по Эвери с пустой рукой: показать его инвентарь. ПКМ с предметом: отдать ему (дальше сам решит, что делать;
можно написать «не надевай нагрудник»: он запомнит).
